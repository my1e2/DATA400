# Probability and Statistics Coursework Repository

Repository containing coursework, lecture notes, homework assignments, simulations, discussions, and exam preparation materials related to probability and mathematical statistics.

---

## Overview

This repository documents coursework focused on foundational probability theory, random variables, statistical inference, and simulation methods using R.

Materials include:

* Lecture notes
* Homework assignments and solutions
* Discussion worksheets
* Probability simulations in R
* Midterm and final exam practice
* Statistical reference materials
